    ⚙️ How It Works

    This tool uses a weighted regression-style formula to estimate student performance. Each input factor is assigned a weight reflecting its assumed importance:

    FactorWeightDescription
    Previous Exam Marks35%Past performance is the strongest indicator
    Attendance20%Regular class participation matters
    Study Hours20%Converted to a 0–100 score (8 hrs = 100)
    Assignment Completion15%Consistent assignment work helps learning
    Sleep Hours10%Converted to a 0–100 score (8 hrs = 100)

    Extracurricular activity hours are not penalized in the score; instead, they influence contextual suggestions (e.g., balancing time).

    Predicted Marks = (0.35 × Previous Marks) + (0.20 × Attendance) + (0.20 × Study Score) + (0.15 × Assignment) + (0.10 × Sleep Score)

    Note: This is an illustrative educational formula, not a trained or scientifically validated machine learning model. It was not trained on real student data and does not claim any particular accuracy.
